# Post Tracker — проста версія (без термінала)

Той самий трекер результатів кампанії (скриншот → розпізнавання →
валідація → черга → звіт). Ця версія — звичайний Node.js-застосунок
без Cloudflare/Wrangler/D1/R2. Розгортається через сайт Railway,
клацанням мишки.

## Крок 1. Завантажити код на GitHub (без git-команд)

1. Зайдіть на https://github.com і створіть акаунт, якщо ще нема.
2. Натисніть зелену кнопку **"New"** (або "+" у верхньому правому куті
   → "New repository").
3. Дайте назву, наприклад `post-tracker`. Залиште "Public" або
   виберіть "Private" — обидва підходять. Натисніть **Create repository**.
4. На сторінці репозиторію знайдіть посилання **"uploading an existing
   file"** (з'являється одразу під заголовком на порожньому репо).
5. Перетягніть **усі файли й папки з цього архіву** (розпаковані) у
   вікно браузера. GitHub підхопить структуру папок автоматично.
6. Внизу натисніть **Commit changes**.

## Крок 2. Підключити Railway

1. Зайдіть на https://railway.app, натисніть **Login**, увійдіть через
   GitHub-акаунт (той самий, що в кроці 1) — Railway попросить дозвіл
   доступу до репозиторіїв.
2. На головній панелі натисніть **New Project** → **Deploy from GitHub
   repo**.
3. Виберіть репозиторій `post-tracker`, який щойно створили.
4. Railway сам розпізнає, що це Node.js-проєкт (побачить
   `package.json`), і почне збірку автоматично.

## Крок 3. Додати ключ Claude API

1. У проєкті на Railway відкрийте вкладку **Variables**.
2. Натисніть **New Variable**.
3. Ім'я: `ANTHROPIC_API_KEY`, значення: ваш ключ. Зберегти.

## Крок 4. Увімкнути постійне сховище (щоб дані не стирались)

Без цього кроку весь прогрес (черга, звіти, скриншоти) буде стиратись
щоразу, як Railway оновлює застосунок.

1. У проєкті відкрийте вкладку **Volumes** (або "Settings" → "Volumes"
   залежно від версії інтерфейсу).
2. Натисніть **New Volume**.
3. **Mount path** вкажіть: `/app/data`
4. Збережіть.
5. Поверніться у **Variables** і додайте ще одну змінну:
   Ім'я: `DATA_DIR`, значення: `/app/data`

## Крок 5. Отримати публічну адресу

1. Вкладка **Settings** → розділ **Networking** (або "Domains").
2. Натисніть **Generate Domain**.
3. Railway видасть посилання виду `post-tracker-production.up.railway.app`
   — відкрийте його, має завантажитись форма застосунку.

## Готово

Кожного разу, коли захочете оновити код — просто заміните файли на
GitHub (той самий спосіб перетягування) або попросіть мене підготувати
оновлену версію архіву; Railway автоматично передеплоїть застосунок
при зміні репозиторію.

## Скільки це коштує

Перші $5 використання — безкоштовно (пробний період, без прив'язки
картки на старті). Далі мінімум ~$5/місяць на плані Hobby. Для одного
невеликого застосунку такого типу цього зазвичай достатньо з запасом.

## Що робити, якщо щось не так

- **Сторінка не відкривається** — перевірте вкладку **Deployments**,
  подивіться логи останнього деплою на помилки.
- **"Файл скриншота обов'язковий" / помилка при завантаженні** —
  переконайтесь, що обрали файл у формі перед натисканням кнопки.
- **Дані зникли після оновлення** — означає, що крок 4 (Volume +
  DATA_DIR) не був виконаний чи мав неправильний шлях. Обидва значення
  (mount path і DATA_DIR) мають бути однаковими: `/app/data`.
